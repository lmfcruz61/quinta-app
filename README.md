# Quinta da Ponte – Guest App

Sistema de gestão de hóspedes para alojamento local.

## Funcionalidades
- Login por código de acesso
- Seleção de pequeno-almoço
- Alteração de horário
- Multi-idioma (PT, EN, FR, ES, DE)
- Painel administrativo Django

## Tecnologias
- Python
- Django
- SQLite
- HTML/CSS
